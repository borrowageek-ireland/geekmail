GeekMail adds a WordPress admin menu with three email management links and Cluster A mail client setup instructions.

== Installation ==
1. In WordPress, go to Plugins > Add New Plugin > Upload Plugin.
2. Upload geekmail.zip and click Install Now.
3. Activate GeekMail.
4. Click GeekMail in the left-hand admin menu.

== Notes ==
This plugin does not store email passwords, manage mailboxes directly, or change WordPress mail delivery settings.
